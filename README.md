# SIH-2025-main

This repository preserves the project exactly as opened in the workspace. The application source is kept in the existing `SIH-2025-main/` folder.

## Project

AyurSutra is a Panchakarma patient management system built for SIH 2025. It includes a Next.js frontend and an Express/MongoDB backend.

## Repository Layout

```text
.
`-- SIH-2025-main/
    |-- app/
    |-- backend/
    |-- components/
    |-- contexts/
    |-- hooks/
    |-- lib/
    |-- styles/
    `-- types/
```

## Getting Started

```bash
cd SIH-2025-main
npm install
cd backend
npm install
```

Run the frontend and backend from separate terminals:

```bash
cd SIH-2025-main
npm run dev
```

```bash
cd SIH-2025-main/backend
npm start
```

See `SIH-2025-main/README.md` for the full project documentation.
